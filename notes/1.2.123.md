# Alt accounts keep applying to the main's party
- With two alt accounts joining the same main, one could get in while the other sat on "Waiting for the party board…" forever. The main answers one application at a time, so the second application could be dropped, and the alt never tried again.
- An application that has not been answered after 30 seconds is now sent again, for as long as the alt is outside the main's party. The check already ran on every tick; only this wait was open-ended.
> Found by reading the code with two alts in mind; not yet confirmed on a live server. If an alt still fails to join, its status line under Party says why.
