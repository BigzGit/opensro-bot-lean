# Detailed activity log, pop-out session window and return choices
- Structured activity history (from Joggio's contribution): categories, outcomes, session markers and grouped repeats, with filters, search, pause and follow, a bounded optional 10-minute command capture, and a local export with a preview (names, free text and positions left out unless you tick raw). Nothing is uploaded.
- Messages use monster names and plain language. Cast code 5 becomes one "Skill not ready yet" row with a count. Select log text and press Ctrl+C to copy it.
- Session window with live totals and the log: open it with the Session button or Pop out in Settings. It no longer opens by itself when you start hunting.
- The feedback line and the status lines stay on the main panel, as before.
- Potion delay in milliseconds, saved per character. Town revival can reverse to the last return-scroll point (the default, so the bot lands in its hunting area) or to where you died. The death spot is only used when you died inside the hunting area, because hunting starts again only from inside it.
