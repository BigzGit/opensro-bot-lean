# Fix attack retries carrying over to other monsters
- Fixed skills being falsely paused while the character was still approaching a monster outside skill reach.
- Attack rejection pauses now apply to the affected monster, so a failed target does not leave skills paused against the next one.
- Silent rejection checks now require the same selected target, known skill reach and fresh game state without pending movement, selection or inventory work.
> The existing weaker-attacker priority remains in effect. Validated with 360 integration tests; live gameplay confirmation is still pending.
