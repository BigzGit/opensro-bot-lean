# Session window, shared logs and return destinations
- Start opens a closable session window with live totals and a down arrow for scrollable logs. Reopen it with Session.
- Settings and the session window share the full retained activity history, including command messages. New entries follow only while reading at the bottom.
- Supplies now accepts a potion delay in whole milliseconds, saved per character.
- Town revival can reverse to the death location or the last return-scroll location. Service trips return to their departure point; missing destinations stop instead of falling back.
> Closing the session window does not stop hunting. Existing inventory sell protections remain in effect.
