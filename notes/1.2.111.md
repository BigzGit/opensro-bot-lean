# Useful refusals without routine warning spam
- Routine cast-not-ready refusals appear as one informational “Skill not ready yet” row, with a repeat count on the right instead of repeated warnings.
- Standard exports include the request type, decoded explanation where known, client state and nearby commands. Nearby commands are explicitly not an exact request match.
- Repeated refusals are grouped, even with other activity in between. Exports retain up to eight recent command-context examples per group. Persistent cast-readiness stalls receive a limited warning.
> Cast code 5 means cooldown or action recovery in OpenSRO. The same number on another channel is not assigned that meaning. Gameplay and retry behavior are unchanged.
