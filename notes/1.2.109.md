# Structured activity history and local export
- Normal activity and optional ten-minute command traces have separate bounded histories, with categories, outcomes, session markers and grouped repeats.
- Game refusals, alchemy results, town stages, confirmed potion consumption and state changes now reach the shared views.
- Both log views offer category/severity filters, search, pause/resume, follow-latest and deliberate history clearing.
- Export opens a local preview first. Standard exports omit free-form messages; raw messages require an explicit checkbox. Nothing is uploaded.
> Requested commands are distinct from confirmed results. Routine skill action observations stay in detailed capture.
