# Clearer activity messages
- Activity windows use monster names and plain-language messages without internal category/outcome prefixes.
- Town steps, loot, potions and movement have simpler descriptions. Missing monster names use a friendly fallback rather than an ID.
- Diagnostic exports retain event codes and outcomes, with monster IDs, selection policy and distance where available. Raw message export remains an explicit choice.
- Selecting log text and pressing Ctrl+C is protected from game shortcuts and copies the selected lines as plain text.
> Targeting behavior is unchanged. The configured priority is diagnostic context, not proof that a monster was attacking you.
